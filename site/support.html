Support

Lurent turns a photograph into an abstract wallpaper. Pick a picture, shape it with the effect controls, set it as your desktop.

Getting started

Choosing a picture

Three sources, switched with the Source menu: search Unsplash, pick from your Photos library, or open a file from your Mac. The Liquid style needs no picture at all — it generates its image from the colour controls.

Light and dark

A wallpaper has two faces. Use the Light / Dark switch above the preview to design each one, and the button next to it to copy one over to the other as a starting point. macOS swaps between them with your system appearance.

Setting the wallpaper

“Set as Desktop” applies it to every display. Every creation stays in your collection — the strip on the left — so you can go back to an earlier one at any time and put it back.

Projects

Each creation is a .lurent document holding the source photo, the settings and the render. There is no save button: changes are written as you make them. The “+” button duplicates the open project so you can branch off a variation without losing the original.

Where they live

In iCloud, so they follow you between Macs. Mac App Store version: in Lurent's own iCloud Drive folder. Version downloaded from this site: in iCloud Drive/Lurent/. With iCloud Drive turned off, projects stay local in Application Support.

Renaming

Project names come from the photo, so there is nothing to fill in. If you want your own name, rename the .lurent document in the Finder — Lurent picks that up and stops renaming it for you.

Sharing one

“Export Project…” writes the whole editable document out; whoever opens it gets your settings, not just a finished picture. “Export as HEIC…” gives you the plain wallpaper file instead.

Common questions

My wallpaper looks soft or cropped on one display

Lurent renders one large square master and macOS centre-crops it per screen, so the same wallpaper fits landscape and portrait displays at native resolution. Use the Crop slider to choose which part of the photo ends up in the middle.

Unsplash search returns nothing

Search runs against Unsplash's API and shares a rate limit across everyone using the app. If it is quiet for a while, wait an hour and try again — or use a photo from Photos or Files, which have no limit.

An older wallpaper disappeared

Versions before 0.10 kept only the last two creations. From 0.10 on every creation is kept, and the ones that survived the old behaviour were brought forward automatically.

Requirements

macOS 26 or later, Apple silicon or Intel.

Get in touch

Bugs, requests, or something that just does not work: hello@lurent.app. Telling us your macOS version and what you were doing helps more than you would think.
